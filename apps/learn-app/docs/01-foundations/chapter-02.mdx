## Introduction

Building physical AI systems requires managing complexity across hardware, sensors, actuators, perception, planning, and control. The Robot Operating System (ROS 2) provides the middleware and tools to orchestrate these components effectively.

This chapter introduces the robotics software stack and ROS 2 fundamentals.

## Core Concepts

### 1. The Robotics Software Stack

Modern robotics systems are typically organized in layers:

```
┌─────────────────────────────────────┐
│  Application Layer                  │  ← High-level AI (planning, learning)
├─────────────────────────────────────┤
│  Middleware Layer (ROS 2)           │  ← Communication, coordination
├─────────────────────────────────────┤
│  Driver Layer                       │  ← Hardware interfaces
├─────────────────────────────────────┤
│  Operating System (Linux)           │  ← Resource management
├─────────────────────────────────────┤
│  Hardware Layer                     │  ← Sensors, actuators, compute
└─────────────────────────────────────┘
```

### 2. Why ROS 2?

ROS 2 is the de facto standard for robotics development because it provides:

- **Modularity**: Components communicate via standard interfaces
- **Scalability**: From single robots to multi-robot systems
- **Real-time capable**: DDS middleware supports hard real-time constraints
- **Cross-platform**: Works on Linux, Windows, macOS
- **Rich ecosystem**: Thousands of pre-built packages

**Key differences from ROS 1**:
- Real-time support via DDS
- Better security
- Native multi-robot communication
- No single point of failure (no roscore)

## Hands-On Tutorial: First ROS 2 Node

```python
# File: my_first_node.py
import rclpy
from rclpy.node import Node
from std_msgs.msg import String

class MinimalPublisher(Node):
    def __init__(self):
        super().__init__('minimal_publisher')
        self.publisher_ = self.create_publisher(String, 'topic', 10)
        self.timer = self.create_timer(0.5, self.timer_callback)
        self.i = 0

    def timer_callback(self):
        msg = String()
        msg.data = f'Hello Physical AI: {self.i}'
        self.publisher_.publish(msg)
        self.get_logger().info(f'Publishing: "{msg.data}"')
        self.i += 1

def main(args=None):
    rclpy.init(args=args)
    node = MinimalPublisher()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()
```
