## Core Concepts

### Sensor Types

- **Vision**: Cameras (RGB, depth, stereo)
- **Range**: LiDAR, ultrasonic, radar
- **Inertial**: IMU (accelerometer + gyroscope)
- **Proprioceptive**: Joint encoders, force/torque sensors
- **Tactile**: Pressure sensors, skin sensors

### Basic Image Processing

```python
import cv2
import numpy as np

def detect_edges(image_path):
    """Simple edge detection pipeline"""
    img = cv2.imread(image_path, cv2.IMREAD_GRAYSCALE)
    blurred = cv2.GaussianBlur(img, (5, 5), 0)
    edges = cv2.Canny(blurred, 50, 150)
    return edges
```
