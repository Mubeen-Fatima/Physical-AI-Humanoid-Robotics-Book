## Introduction

## Core Concepts

### 1. Unity vs Gazebo

| Aspect | Gazebo | Unity |
|--------|---------|-------|
| **Physics** | Excellent (ODE/Bullet) | Good (PhysX) |
| **Graphics** | Basic (OGRE) | Photorealistic (HDRP) |
| **Use Case** | Navigation, control | Vision, HRI, synthetic data |
| **Setup** | ROS native | Requires TCP bridge |
| **Performance** | CPU-intensive | GPU-accelerated |

### 2. ROS-Unity Setup

```bash
# In Unity Package Manager, add:

# In ROS 2 workspace:
git clone https://github.com/Unity-Technologies/ROS-TCP-Endpoint
colcon build
```

### 3. Unity-ROS Communication

```csharp
// Unity C# script
using UnityEngine;
using Unity.Robotics.ROSTCPConnector;
using RosMessageTypes.Geometry;

public class RobotController : MonoBehaviour
{
    ROSConnection ros;
    public string topicName = "cmd_vel";

    void Start()
    {
        ros = ROSConnection.GetOrCreateInstance();
        ros.RegisterPublisher<TwistMsg>(topicName);
    }

    void Update()
    {
        // Send velocity command
        var twist = new TwistMsg();
        twist.linear.x = Input.GetAxis("Vertical");
        twist.angular.z = Input.GetAxis("Horizontal");
        ros.Publish(topicName, twist);
    }
}
```

**ROS 2 endpoint**:

```bash
ros2 run ros_tcp_endpoint default_server_endpoint --ros-args -p ROS_IP:=0.0.0.0
```
