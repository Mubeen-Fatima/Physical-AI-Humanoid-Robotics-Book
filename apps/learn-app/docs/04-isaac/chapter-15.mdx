## Introduction

Isaac Gym enables training robot policies 10-100x faster than traditional simulators by running thousands of environments in parallel on GPU. This chapter teaches massively parallel RL for robotics.

## Core Concepts

### 1. GPU-Parallel RL Architecture

```
CPU: Policy Network → Actions
  ↓
GPU: 4096 Parallel Environments
  ├─ Env 1: Robot → Observation, Reward
  ├─ Env 2: Robot → Observation, Reward
  ...
  └─ Env 4096: Robot → Observation, Reward
  ↓
CPU: Collect Rollouts → Update Policy
```

**Speed comparison**:
- Traditional RL (single env): ~10 FPS
- Isaac Gym (4096 envs): ~40,000 FPS

```python
        success_bonus = (distances < 0.05).float() * 10.0
```

### 3. PPO Training Loop

```python
# ppo_trainer.py
import torch
import torch.nn as nn
from torch.distributions import Normal

class PPOAgent:
    def __init__(self, obs_dim, action_dim):
        self.policy = nn.Sequential(
            nn.Linear(obs_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, action_dim)
        ).cuda()

        self.value = nn.Sequential(
            nn.Linear(obs_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 1)
        ).cuda()

        self.optimizer = torch.optim.Adam(
            list(self.policy.parameters()) + list(self.value.parameters()),
            lr=3e-4
        )

    def act(self, obs):
        """Select actions for all environments"""
        mean = self.policy(obs)
        std = torch.ones_like(mean) * 0.1
        dist = Normal(mean, std)
        actions = dist.sample()
        log_probs = dist.log_prob(actions).sum(dim=-1)

        return actions, log_probs

    def update(self, rollouts):
        """PPO update"""
        obs, actions, old_log_probs, returns, advantages = rollouts

        # Compute new log probs
        mean = self.policy(obs)
        std = torch.ones_like(mean) * 0.1
        dist = Normal(mean, std)
        new_log_probs = dist.log_prob(actions).sum(dim=-1)

        # PPO clipped objective
        ratio = torch.exp(new_log_probs - old_log_probs)
        clip_ratio = torch.clamp(ratio, 0.8, 1.2)

        policy_loss = -torch.min(
            ratio * advantages,
            clip_ratio * advantages
        ).mean()

        # Value loss
        value_pred = self.value(obs).squeeze()
        value_loss = (value_pred - returns).pow(2).mean()

        # Total loss
        loss = policy_loss + 0.5 * value_loss

        # Update
        self.optimizer.zero_grad()
        loss.backward()
        self.optimizer.step()

        return loss.item()

# Training loop
```
