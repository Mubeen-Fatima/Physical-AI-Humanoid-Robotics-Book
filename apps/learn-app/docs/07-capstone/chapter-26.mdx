## Project Options

### Option 1: Warehouse Humanoid Assistant

**Goal**: Deploy a humanoid robot in a warehouse for package sorting

**Requirements**:
- Navigate warehouse environment autonomously
- Detect and classify packages using vision
- Pick packages and place in correct bins
- Handle dynamic obstacles (humans, forklifts)
- Natural language interface for task assignment

**Technology Stack**:
- **Simulation**: Isaac Sim for development and testing
- **Perception**: RT-2 or similar VLA model for vision-language understanding
- **Navigation**: ROS 2 Nav2 stack
- **Manipulation**: Whole-body control (Chapter 21)
- **Locomotion**: Bipedal walking controller (Chapter 20)

### Option 2: Kitchen Assistant Robot

**Goal**: Robot that can prepare simple meals following recipes

**Requirements**:
- Understand recipe instructions (language)
- Locate ingredients and tools (vision + spatial reasoning)
- Manipulate objects (grasping, pouring, stirring)
- Coordinate bimanual tasks
- Detect task completion and errors

**Technology Stack**:
- **Simulation**: Gazebo + Unity for photorealistic rendering
- **VLA**: Custom model trained on cooking demonstrations
- **Perception**: Multimodal (RGB-D, tactile, force sensors)
- **Control**: Task-space control with compliance

### Option 3: Outdoor Delivery Robot

**Goal**: Autonomous robot for last-mile package delivery

**Requirements**:
- Navigate outdoor environments (sidewalks, crosswalks)
- Robust to weather and lighting changes
- Detect and avoid pedestrians
- Secure package compartment
- GPS + visual odometry localization

**Technology Stack**:
- **Simulation**: Gazebo with outdoor environments
- **Perception**: LiDAR + camera fusion
- **Navigation**: Nav2 with dynamic obstacle avoidance
- **Mapping**: SLAM with long-term localization

```python
# perception_node.py
class PerceptionNode(Node):
    def __init__(self):
        super().__init__('perception_node')

        # Subscribers
        self.rgb_sub = self.create_subscription(
            Image, '/camera/rgb', self.rgb_callback, 10
        )
        self.depth_sub = self.create_subscription(
            Image, '/camera/depth', self.depth_callback, 10
        )

        # Publishers
        self.detections_pub = self.create_publisher(
            DetectionArray, '/detections', 10
        )

        # Load models
        self.vla_model = self.load_vla_model()

    def rgb_callback(self, msg):
        # Convert ROS image to numpy
        image = self.bridge.imgmsg_to_cv2(msg, "rgb8")

        # Run detection
        detections = self.vla_model.detect(image)

        # Publish
        self.publish_detections(detections)
```
