## Introduction

The sim-to-real gap—the performance difference between simulated and real environments—is robotics' greatest challenge. This chapter teaches proven techniques to bridge this gap.

## Core Concepts

### 1. Sources of Sim-to-Real Gap

- **Physics modeling**: Friction, contact dynamics, deformation
- **Sensor characteristics**: Noise, latency, field of view
- **Actuator dynamics**: Backlash, compliance, delays
- **Environmental factors**: Lighting, textures, acoustics

        self.measured_data = []

    def collect_data(self, command, response):
        """Collect input-output pairs from real robot"""
        self.measured_data.append({
            'cmd': command,
            'response': response
        })

    def identify_parameters(self):
        """Fit model parameters to real data"""
        def cost_function(params):
            total_error = 0
            for sample in self.measured_data:
                predicted = self.simulate_with_params(
                    sample['cmd'],
                    params
                )
                error = np.linalg.norm(
                    predicted - sample['response']
                )

### 4. Reality Gap Metrics

```python
class RealityGapMetrics:
    def __init__(self):
        self.sim_trajectories = []
        self.real_trajectories = []

    def compute_gap(self):
        """Compute discrepancy between sim and real"""
        # Position error
        pos_error = np.mean([
            np.linalg.norm(s[:3] - r[:3])
            for s, r in zip(self.sim_trajectories, self.real_trajectories)
        ])

        # Velocity error
        vel_error = np.mean([
            np.linalg.norm(s[3:] - r[3:])
            for s, r in zip(self.sim_trajectories, self.real_trajectories)
        ])

        return {
            'position_rmse': pos_error,
            'velocity_rmse': vel_error
        }
```
